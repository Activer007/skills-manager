# 用户旅程场景文档

> **版本**: v1.0 | **最后更新**: 2025-01-29 | **维护者**: Skill Master Team

## 📚 文档概述

本文档描述了 Skill Master 的 **5 个核心用户旅程**，涵盖从新用户入门到高级用户工作流的完整体验。

### 用户角色定义

| 角色 | 技能水平 | 使用频率 | 核心需求 | 代表性旅程 |
|------|---------|---------|---------|-----------|
| **新用户** | 初级 | 低频探索 | 快速上手，发现价值 | 旅程 1: 新用户入门 |
| **普通用户** | 中级 | 高频使用 | 高效管理，稳定运行 | 旅程 2: 日常管理 |
| **高级用户** | 高级 | 中频配置 | 深度定制，批量操作 | 旅程 3: 高级工作流 |
| **创作者** | 专家 | 高频创作 | 发布分享，获取反馈 | 旅程 4: 创作发布 |
| **管理员** | 专家 | 低频维护 | 系统管理，安全保障 | 旅程 5: 系统维护 |

## 🚀 旅程 1: 新用户入门

> **流程图**: [`new-user-onboarding.mermaid`](../diagrams/user-journeys/new-user-onboarding.mermaid)

### 基本信息

| 字段 | 值 |
|------|-----|
| **旅程ID** | UJ-01 |
| **用户角色** | 新用户（初级） |
| **使用频率** | 一次性（首次使用） |
| **复杂度** | 简单 |
| **预计耗时** | 10-15 分钟 |
| **核心目标** | 快速理解应用价值，成功安装第一个 Skill |

### 旅程描述

**场景背景**:
用户首次安装并启动 Skill Master 应用，对 Claude Code Skills 的概念不熟悉，希望通过最简单的方式了解应用功能并尝试安装第一个 Skill。

**用户动机**:
- 听说 Skill Master 可以管理 Claude Code Skills
- 想要提升 Claude Code 的使用效率
- 希望发现社区中的优质 Skills

**业务价值**:
- 降低新用户的学习成本
- 快速展示应用核心价值
- 提升用户留存率和活跃度

### 错误处理

| 错误类型 | 触发条件 | 错误提示 | 恢复方法 |
|---------|---------|---------|---------|
| **网络错误** | 无法连接 GitHub | "网络连接失败，请检查网络设置" | 检查网络，稍后重试 |
| **仓库不存在** | GitHub 仓库链接错误 | "仓库不存在或已删除" | 检查链接是否正确 |
| **API 限流** | GitHub API 限流 | "GitHub API 限流，请配置 Token" | 配置 GitHub Token |
| **安全阻断** | 安全扫描发现严重风险 | "安全扫描未通过，无法安装" | 查看安全报告，了解风险 |
