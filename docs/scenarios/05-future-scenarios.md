## 🚀 核心功能增强（v2.7.0 - v2.9.0）

### 场景 1: 自动更新 Skills

**场景ID**: FS-01
**优先级**: 🔴 高
**复杂度**: 中等
**预计版本**: v2.7.0

#### 场景描述

**背景**: Skills 不断更新迭代，用户希望自动获取最新版本。

**用户动机**:
- 保持 Skills 最新状态
- 获取新功能和 bug 修复
- 减少手动更新工作

#### 流程步骤

##### 步骤 1: 定期检查更新

**系统行为**:
- 每日自动检查已安装 Skills 的更新
- 对比本地版本与市场版本
- 显示更新通知

**UI 元素**:
```
┌─────────────────────────────────────────┐
│ 🔔 发现 3 个 Skills 有更新可用            │
│                                          │
│ 📦 Frontend Design: v1.0.0 → v2.0.0     │
│ 📦 UI Components: v1.5.0 → v1.6.0        │
│ 📦 Doc Writer: v2.0.0 → v2.1.0           │
│                                          │
│ [查看详情]  [全部更新]  [稍后提醒]      │
└─────────────────────────────────────────┘
```

##### 步骤 2: 用户查看更新详情

**用户操作**: 点击 **"查看详情"**

**系统响应**: 显示更新详情对话框

**UI 元素**:
```
┌─────────────────────────────────────────┐
│ Skill 更新详情              [×]        │
├─────────────────────────────────────────┤
│ 📦 Frontend Design                      │
│ 当前版本: v1.0.0                         │
│ 最新版本: v2.0.0                         │
│                                          │
│ 📝 更新日志:                             │
│ • 新增: 支持深色模式                      │
│ • 优化: 性能提升 30%                      │
│ • 修复: 修复内存泄漏问题                  │
```

**系统行为**:

```rust
#[tauri::command]
async fn check_skill_updates() -> Result<Vec<SkillUpdate>, String> {
    let installed_skills = db::get_installed_skills()?;
    let mut updates = Vec::new();

    for skill in installed_skills {
        if let Some(market_skill) = db::get_marketplace_skill(&skill.name)? {
            if skill.version != market_skill.version {
                updates.push(SkillUpdate {
                    name: skill.name,
                    current_version: skill.version,
                    latest_version: market_skill.version,
                    changelog: get_changelog(&market_skill.source_url)?,
                });
            }
        }
    }

    Ok(updates)
}
```

**复杂度**: 复杂
**预计版本**: v2.9.0

**背景**: 某些 Skills 依赖其他 Skills 才能正常工作（例如：React Expert 依赖 Frontend Design）。

**用户动机**:
- 自动安装依赖
- 避免缺失依赖导致的功能异常
- 简化安装流程

#### 流程步骤

##### 步骤 1: 定义依赖关系

**SKILL.md frontmatter**:
```yaml
---
name: react-expert
description: React expert
version: 1.0.0
dependencies:
  - name: frontend-design
    version: ">=1.0.0"
  - name: ui-components
    version: ">=1.5.0"
---
```

##### 步骤 2: 安装时自动检测依赖

**系统行为**:
- 解析 SKILL.md
- 检查依赖是否已安装
- 显示依赖列表

**UI 元素**:
```

│                                          │
│ [取消]  [安装依赖并继续]                │
└─────────────────────────────────────────┘
```

##### 步骤 3: 自动安装依赖

**系统行为**:
- 按顺序安装依赖
- 等待所有依赖安装完成
- 安装主 Skill

##### 步骤 4: 依赖冲突检测

**系统行为**:
- 检测版本冲突
- 检测循环依赖
- 显示冲突警告
