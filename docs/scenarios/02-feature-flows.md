### SC-01: 从 GitHub 导入 Skill

> **流程图**: [`import-from-github.mermaid`](../diagrams/feature-flows/skill-management/import-from-github.mermaid) 📝 待创建

#### 基本信息

| 字段 | 值 |
|------|-----|
| **场景ID** | SC-01 |
| **用户角色** | 所有用户 |
| **使用频率** | 中频（每周使用） |
| **复杂度** | 中等 |
| **适用版本** | v2.0.0+ |

#### 场景描述

**场景背景**: 用户在市场或来源页面发现感兴趣的 Skill，从 GitHub 仓库导入到本地。

**用户动机**: 安装社区优质 Skills，扩展 Claude Code 功能。

**业务价值**: 核心功能，连接市场与用户。

#### 流程步骤

##### 步骤 1: 用户触发导入

**入口位置**:
- 市场页面 (`/marketplace`) → Skill 卡片 → **"安装"** 按钮
- 来源页面 (`/repositories`) → 仓库列表 → **"扫描并安装"** 按钮

**用户操作**: 点击 **"安装"** 按钮

**系统响应**:
- 显示确认对话框（可选）
- 创建后台任务
- 显示进度提示

**UI 元素**:
```
Toast 提示:
┌─────────────────────────────────────────┐
│ 📥 正在安装 Frontend Design...            │
│ ████████░░ 80%                          │
└─────────────────────────────────────────┘
```

##### 步骤 2: 下载 Skill 文件

**后端处理**:
- 调用 `import_github_skill_with_progress` 命令
- 从 GitHub API 获取仓库信息
- 下载 SKILL.md 和相关文件

**相关代码**:
- 后端: `src-tauri/src/commands/share.rs` - `import_github_skill_with_progress`

##### 步骤 3: 解析 SKILL.md

**后端处理**:
- 读取 SKILL.md 文件
- 解析 frontmatter（name, description, version, author）
- 提取 Skill 内容

**错误处理**:
- SKILL.md 缺失 → 显示错误："仓库中未发现 SKILL.md"
- frontmatter 格式错误 → 容错处理，使用默认值

##### 步骤 4: 安全扫描

**后端处理**:
- 调用 `scan_skill_security` 命令
- 检测安全风险（命令注入、敏感信息泄露等）
- 生成安全报告

**安全等级**:
- 🟢 **安全** (Safe): 无风险
- 🟡 **风险** (Risk): 有潜在风险，提示用户
- 🔴 **阻断** (Blocked): 严重风险，阻止安装

**相关代码**:
- 后端: `src-tauri/src/commands/security.rs` - `scan_skill_security`

##### 步骤 5: 质量评分

**后端处理**:
- 调用 `analyze_skill_quality` 命令
- 评估内容质量、技术实现、维护性、用户体验
- 生成评分（0-100 分）

**评分等级**:
- **S 级**: 90-100 分（卓越）
- **A 级**: 80-89 分（优秀）
- **B 级**: 70-79 分（良好）
- **C 级**: 60-69 分（合格）
- **D 级**: 0-59 分（需改进）

**相关代码**:
- 后端: `src-tauri/src/commands/analyzer.rs` - `analyze_skill_quality`

##### 步骤 6: 安装到本地

**后端处理**:
- 复制 Skill 文件到目标目录
  - 系统级: `~/.claude/skills/[skill-name]/`
  - 项目级: `[项目根目录]/.claude/skills/[skill-name]/`
- 更新数据库（`installed_skills` 表）
- 发送任务完成事件

**相关代码**:
- 后端: `src-tauri/src/commands/skill.rs` - `install_skill`

##### 步骤 7: 显示安装成功

**前端处理**:
- 监听任务完成事件（`useTaskListener` Hook）
- 显示成功提示
- 刷新"我的 Skills"列表

**UI 元素**:
```
Toast 提示:
┌─────────────────────────────────────────┐
│ ✅ Frontend Design 安装成功！             │
│                                          │
│ 已安装到系统级 Skills                    │
│ [查看]  [启用]  [关闭]                   │
└─────────────────────────────────────────┘
```

#### 成功标准

- [ ] Skill 成功从 GitHub 下载
- [ ] SKILL.md 解析成功
- [ ] 安全扫描完成（无严重风险）
- [ ] 质量评分生成
- [ ] Skill 安装到本地目录
- [ ] 数据库记录创建成功

#### 错误处理

| 错误类型 | 触发条件 | 错误提示 | 恢复方法 |
|---------|---------|---------|---------|
| **网络错误** | 无法连接 GitHub | "网络连接失败，请检查网络设置" | 检查网络，稍后重试 |
| **仓库不存在** | GitHub 仓库 404 | "仓库不存在或已删除" | 检查仓库链接 |
| **SKILL.md 缺失** | 仓库不包含 SKILL.md | "仓库中未发现 SKILL.md" | 确认仓库结构正确 |
| **API 限流** | GitHub API 限流 | "GitHub API 限流，请配置 Token" | 配置 GitHub Token |
| **安全阻断** | 安全扫描发现严重风险 | "安全扫描未通过，无法安装" | 查看安全报告，了解风险 |
| **磁盘空间不足** | 目标磁盘空间不足 | "磁盘空间不足，无法安装" | 清理磁盘空间 |

### SC-03: 从 Skill 包导入

> **流程图**: [`import-from-package.mermaid`](../diagrams/feature-flows/skill-management/import-from-package.mermaid) 📝 待创建

#### 基本信息

| 字段 | 值 |
|------|-----|
| **场景ID** | SC-03 |
| **用户角色** | 所有用户 |
| **使用频率** | 低频（每月使用） |
| **复杂度** | 简单 |
| **适用版本** | v2.5.0+ |

#### 场景描述

**场景背景**: 用户收到一个 `.zip` Skill 包文件，希望导入到 Skill Master。

**用户动机**: 离线分享、批量安装、备份恢复。

#### 流程步骤

##### 步骤 1: 用户选择 .zip 文件

**入口位置**: "我的 Skills"页面 → **"导入"** 按钮 → **"从包文件"**

**用户操作**:
- 点击 **"从包文件"**
- 在文件选择器中选择 `.zip` 文件

##### 步骤 2: 验证包格式

**后端处理**:
- 解压 `.zip` 文件
- 验证是否包含 `skill-manifest.json`（必需）
- 验证包签名（可选）

**错误处理**:
- 无效的包格式 → 显示错误："无效的 Skill 包文件"
- 签名验证失败 → 显示警告："包签名验证失败，可能存在安全风险"

##### 步骤 3: 读取包元数据

**后端处理**:
- 读取 `skill-manifest.json`
- 提取 Skill 元数据（name, description, version, author, checksum）

##### 步骤 4: 验证完整性

**后端处理**:
- 计算 Skill 文件的 SHA-256 校验和
- 与 `skill-manifest.json` 中的 `checksum` 对比

**错误处理**:
- 校验和不匹配 → 显示错误："Skill 包已损坏或被篡改"

##### 步骤 5: 安装 Skill

**后端处理**:
- 复制 Skill 文件到目标目录
- 更新数据库
- 记录包来源

#### 成功标准

- [ ] .zip 文件验证通过
- [ ] 包元数据读取成功
- [ ] 完整性验证通过
- [ ] Skill 安装成功

#### 错误处理

| 错误类型 | 触发条件 | 错误提示 | 恢复方法 |
|---------|---------|---------|---------|
| **无效的包格式** | .zip 文件格式错误 | "无效的 Skill 包文件" | 检查文件来源 |
| **包已损坏** | 校验和不匹配 | "Skill 包已损坏或被篡改" | 重新获取包文件 |
| **签名验证失败** | 签名不匹配 | "包签名验证失败，可能存在安全风险" | 谨慎安装 |

#### 当前实现状态

- **状态**: ✅ 已完成
- **完成度**: 100%
- **相关文件**:
  - 前端: `src/pages/MySkills.tsx`
