# Skill Master 快速开始指南

> **阅读时间**: 5 分钟 | **适用对象**: 新用户、产品经理、开发者 | **最后更新**: 2025-01-29

## 🎯 5 分钟了解 Skill Master

Skill Master 是一个**桌面应用程序**，用于管理 Claude Code Skills。想象一下"应用商店"或"插件管理器"，但专门为 Claude Code 的 Skills 设计。

### 核心价值

- **📦 发现和安装**: 从市场浏览和安装社区 Skills
- **🔧 便捷管理**: 启用/禁用、配置、卸载已安装的 Skills
- **🛡️ 安全保障**: 自动安全扫描和质量评分
- **🔗 分享交流**: 4 种方式分享 Skills，一键安装分享链接

**侧边栏导航**（从上到下）:

- 📚 **我的 Skills** (`/my-skills`) - 管理已安装的 Skills

## 🎨 核心功能概览

### 1. 我的 Skills（核心功能）

**路径**: `/my-skills`

**功能**:
- ✅ 查看所有已安装的 Skills（系统级/项目级）
- ✅ 启用/禁用 Skill（开关按钮）
- ✅ 配置 Skill 参数（动态表单）
- ✅ 查看 Skill 详情（SlideOver 侧边抽屉）
- ✅ 分享 Skill（4 种方式）
- ✅ 卸载 Skill
- ✅ Fork/Remix Skill（基于现有 Skill 创建副本）

**典型场景**:
- 用户每天打开应用，检查哪些 Skill 启用中
- 根据项目需求，临时启用某些 Skill
- 配置 Skill 参数（例如：API 端点、模型选择）

---

### 2. 市场浏览（发现功能）

**路径**: `/marketplace`

**功能**:
- ✅ 浏览市场中的所有 Skills
- ✅ 搜索 Skills（FTS5 全文搜索）
- ✅ 按来源筛选（Featured/User Repositories）
- ✅ 按类别和排序（评分、更新时间）
- ✅ 查看安全评分和质量评分
- ✅ 一键安装（实时进度显示）

**典型场景**:
- 用户想要解决特定问题，搜索相关 Skills
- 用户发现优质 Skill，点击安装
- 用户按评分排序，寻找高质量 Skills

---

### 3. Skill 分享（社交功能）

**入口**: "我的 Skills"页面 → Skill 卡片 → "分享"按钮

**4 种分享方式**:

#### 🔗 方式 1: 分享链接（推荐）
- 生成唯一链接（例如: `https://skillmaster.app/share/abc123`）
- 用户打开链接后，点击"安装"即可
- **优势**: 一键安装，无需复制粘贴

#### 📝 方式 2: 文本分享
- 生成多平台分享文本（X/Twitter、微信、邮件）
- 包含 Skill 名称、描述、GitHub 链接
- **优势**: 适合社交媒体分享

#### 🖼️ 方式 3: 图片分享
- 生成精美的分享卡片（PNG 图片）
- 包含二维码、Skill 信息、评分
- **优势**: 视觉吸引，适合朋友圈

#### 📦 方式 4: 包导出
- 导出为 `.zip` 文件（离线分享）
- 包含 Skill 文件和元数据
- **优势**: 离线环境可用

**典型场景**:
- 用户发现优质 Skill，生成分享链接发布到社交媒体
- 用户将 Skill 打包为 `.zip`，在离线环境分享给同事

---

### 4. 合集管理（组织功能）

**路径**: `/collections` → 点击合集 → `/collections/:id`

**功能**:
- ✅ 创建合集（例如："前端开发"、"文档编写"）
- ✅ 将 Skills 添加到合集
- ✅ 拖拽排序（⚠️ *未实现*）
- ✅ 一键启用/禁用合集中的所有 Skills
- ✅ 查看合集详情

**典型场景**:
- 用户创建"前端开发"合集，包含前端设计、UI 组件等 Skills
- 用户启动前端项目时，一键启用"前端开发"合集中的所有 Skills

---

### 5. 安全扫描（保障功能）

**路径**: `/security`、`/scan-history`

**功能**:
- ✅ 自动安全扫描（安装时、定期）
- ✅ 3 种扫描模式（严格/标准/宽松）
- ✅ 查看安全报告（风险等级、问题详情）
- ✅ 管理白名单（信任特定 Skills 或规则）
- ✅ 查看扫描历史（搜索、筛选、导出）

**安全等级**:
- 🟢 **安全** (Safe): 无风险
- 🟡 **风险** (Risk): 有潜在风险，建议检查
- 🔴 **阻断** (Blocked): 严重风险，已阻止安装
- ⚪ **未知** (Unknown): 未扫描

**典型场景**:
- 用户安装 Skill 后，发现安全等级为"风险"
- 用户查看安全报告，了解风险详情
- 用户将信任的 Skill 加入白名单

---

### 6. 质量评分（参考功能）

**路径**: "我的 Skills"页面 → Skill 卡片 → "详情"标签

**评分体系**（100 分制）:
- **内容质量** (50 分): 清晰度、技术深度、文档完整性
- **技术实现** (30 分): 代码质量、模式设计、错误处理
- **维护性** (10 分): 更新频率、社区活跃度
- **用户体验** (10 分): 易用性、可读性

**评分等级**:
- **S 级**: 90-100 分（卓越）
- **A 级**: 80-89 分（优秀）
- **B 级**: 70-79 分（良好）
- **C 级**: 60-69 分（合格）
- **D 级**: 0-59 分（需改进）

**典型场景**:
- 用户在市场浏览时，优先选择 A 级以上的 Skills
- 用户查看质量评分详情，了解改进建议

---

### 7. 来源管理（高级功能）

**路径**: `/repositories`

**功能**:
- ✅ 添加自定义 GitHub 仓库
- ✅ 查看已添加的仓库
- ✅ 扫描仓库中的 Skills
- ✅ 删除仓库（⚠️ *CASCADE 删除矛盾*）
- ✅ 按来源筛选市场 Skills

**来源类型**:
- **Featured**: 官方精选的优质仓库
- **User Repositories**: 用户自定义的仓库

**典型场景**:
- 高级用户添加自己团队的 GitHub 仓库
- 用户从特定仓库扫描和安装 Skills

---

### 8. 任务中心（进度监控）

**路径**: `/tasks`

**功能**:
- ✅ 查看所有任务（安装、扫描、卸载等）
- ✅ 实时进度显示
- ✅ 任务状态筛选（全部/进行中/已完成/失败）
- ✅ 取消任务
- ✅ 查看任务详情

**任务类型**:
- 📥 **安装任务**: 从 GitHub/本地/包导入 Skill
- 🔍 **扫描任务**: 安全扫描、质量评分
- 🗑️ **卸载任务**: 卸载 Skill
- 🔄 **更新任务**: 更新 Skill

**典型场景**:
- 用户从市场安装多个 Skills，在任务中心查看所有进度
- 用户安装失败，查看任务详情了解错误原因

## ⚠️ 常见问题

### Q1: 为什么我看不到"仪表板"页面？

**A**: Dashboard 页面当前未配置路由，虽然功能已完整实现（221 行代码），但无法访问。

**临时解决方案**: 使用"我的 Skills"页面查看统计信息。

**修复计划**: 在 `src/App.tsx` 中添加路由配置（5 分钟工作量）。

---

### Q2: GitHub API 限流怎么办？

**A**: GitHub API 有速率限制（未认证用户：60 次/小时），超过后会显示限流错误。

**解决方案**: 在"设置"中配置 GitHub Personal Access Token（PAT），提升限制至 5000 次/小时。

**配置指南**:
1. 访问 GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 生成新 Token（权限: `repo:status`, `read:org`）
3. 在 Skill Master"设置"中粘贴 Token

---

### Q3: 如何理解安全等级？

**A**: 安全等级由安全扫描系统自动评估，基于以下因素：

- 🟢 **安全**: 无风险问题
- 🟡 **风险**: 有潜在风险（例如：命令注入、敏感信息泄露），建议检查
- 🔴 **阻断**: 严重风险（例如：恶意代码），已阻止安装

**误报处理**: 如果误判，可在"安全"页面将 Skill 加入白名单。

---

### Q4: Skill 安装失败怎么办？

**A**: 常见原因和解决方案：

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| **仓库不存在** | GitHub 仓库链接错误 | 检查链接是否正确 |
| **SKILL.md 缺失** | 仓库不包含 SKILL.md | 确保仓库根目录有 SKILL.md |
| **网络错误** | 网络连接问题 | 检查网络连接，稍后重试 |
| **API 限流** | GitHub API 限流 | 配置 GitHub Token |
| **安全阻断** | 安全扫描发现严重风险 | 查看安全报告，确认风险 |

**查看详细错误**: 在"任务中心"中点击失败任务，查看错误详情。

---

### Q5: 如何批量管理 Skills？

**A**: 当前不支持批量启用/禁用，但可以使用"合集"功能：

1. 创建合集（例如："前端开发"）
2. 将相关 Skills 添加到合集
3. （未来支持）一键启用/禁用合集中的所有 Skills

**临时方案**: 逐个启用/禁用 Skills。

## 🎓 核心概念

### Skill 是什么？

Skill 是 Claude Code 的**可扩展功能模块**，类似于：
- 浏览器的**扩展插件**（Chrome Extensions）
- VS Code 的**扩展**（VS Code Extensions）
- npm 的**包**（npm packages）

**每个 Skill**:
- 包含一个 `SKILL.md` 文件（元数据 + 指令）
- 可以被 Claude Code 识别和加载
- 可以在 Skill Master 市场中浏览和安装

**示例**:
```
📦 frontend-design
├── SKILL.md          # Skill 清单文件
├── README.md         # 详细文档
└── examples/         # 示例文件
```

### 系统级 vs 项目级 Skills

**系统级 Skills**:
- 位置: `~/.claude/skills`
- 作用域: 所有项目
- 典型用途: 通用 Skills（例如：文档编写、代码审查）

**项目级 Skills**:
- 位置: `[项目根目录]/.claude/skills`
- 作用域: 仅当前项目
- 典型用途: 项目特定 Skills（例如：公司内部工具）

### 什么是合集？

合集是**组织和管理 Skills 的集合**，类似于：
- 音乐播放列表
- 代码仓库的标签

**用途**:
- 按项目/主题组织 Skills
- 一键启用/禁用相关 Skills
- 分享给团队成员

**示例**:
- "前端开发"合集：Frontend Design, UI Components, CSS Expert
- "文档编写"合集：Doc Writer, Markdown Expert, Spell Check
